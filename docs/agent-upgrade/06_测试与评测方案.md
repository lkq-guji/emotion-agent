# 06　测试与评测方案

### 现状和测试边界

现有 pnpm test、test:gateway、test:agent、test:startup、test:smoke 及 CI 可复用。此次未运行，以下样本数、门槛和预算均为提案，不是产品成绩。所有破坏性用例使用 mkdtemp 建立的独立库、浏览器临时 profile、假密钥、受控时钟和独立端口。测试禁止指向个人运行目录。

### 数据集与标注

规划 120 个中文任务场景，覆盖七工具、无工具、澄清、多工具、歧义时间、拒绝与越权；每例记录时区/时钟、初始数据、允许和禁止的调用、必要前后顺序、标准化参数、预期卡片与最终数据库状态。另建至少 12 份合成 PDF/TXT/MD，60 个知识问题，含同义、专名短词、跨段和无答案，人工标注可接受的文档版本、块与页。按意图模板和文档族分开发/冻结集，比例约 2:1；近似改写留在同组。两人独立核对歧义标签，保留分歧和最终口径。禁止复制个人日记。

### 指标与放行目标

|维度|计算与初始目标|
|---|---|
|工具调用|可接受工具集合和必要顺序同时命中/样本数，另报逐工具 precision/recall 和无工具误调用率；冻结集目标 ≥90%。|
|参数|对明确字段逐项比较，时间换算 UTC、ID 映射固定夹具，漏填及多填均计错；字段准确率 ≥95%，另报整次全对率。|
|任务完成|用户点击确认后的最终库状态、回执、时间与副作用数全部符合/完整场景数；假模型合同用例 100%，真实模型目标 ≥85%。|
|检索|Recall@5 用前五命中 gold 块个数除以 gold 总数按题平均，MRR@5 取首个相关排名倒数；有答案题目标 Recall@5 ≥0.80。另报引用定位正确率 ≥95%、无答案正确拒答率 ≥90%。|
|向量价值|同一语料与切分，比较 FTS、精确向量、混合 RRF；建议混合对同义题 Recall@5 绝对提升 ≥5 个百分点，整体不倒退才默认开启。报告样本数与置信区间，样本不足时只作观察。|
|权限和恢复|禁止发送的唯一标记出现在出站请求次数=0；未经确认的业务写入=0；已确认操作在重复提交和各故障点恢复后恰好一份。任何失败阻断发布。|
|时延和用量|分别记录模型、索引、检索、总轮次 p50/p95、样本数及硬件；建议 1 万块、热缓存、本机检索 p95 ≤300 ms。冷启动另报；缺失 usage 不计作零。|

### 分层执行

1. 单元层测 Schema 与业务校验、相对时区、中文分词、短词和文本预算、RRF 与引用定位、退避和错误分类。检索评分使用固定排序并规定同分按稳定 ID。
2. 集成层走真实 Express 与临时 SQLite，模型替身依次返回正常工具、非法 JSON、未知工具、重复调用、429/5xx、无 usage、断连。分别在模型返回后、提案落盘后、确认提交后但响应前、浏览器已保存但 ACK 前、索引发布前后中断。重启检查动作数、主外键、策略、回执和状态。
3. Playwright 从房间发消息→确认/拒绝→刷新→成长页核查；从设置撤权后再次问答；导入文件→显示引用→替换→删除；第二个隔离浏览器上下文验证不可访问。复跑原保存聊天、记忆、提醒路径。
4. CI 在现有 Windows/Linux job 添加确定性夹具和迁移演练，Linux 继续桌面 Chromium smoke；新扩展必须双平台验证。锁文件安装和生产 build/start 使用临时数据目录；无供应商密钥也能跑测试。
5. 真模型单独手动触发，用自有密钥、冻结模型标识、请求参数、数据版本与费用上限。每例建议三次，报告真实调用次数、平均及范围。评审关注误执行、误保存、无依据引用。输出 Git SHA、Node/SQLite/模型版本、样本哈希、逐例匿名结果、未知 usage 数、总耗时和失败原因；不提交原始供应商响应。

### 发布判定

先出旧版本基线，再跑同集新版本。授权、隔离、迁移和幂等为硬门槛，单独列错例，不能被平均值掩盖。未跑的真实模型与未跑的平台必须在报告中标为“未测”。
