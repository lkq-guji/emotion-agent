# Agent 2.0 匿名工程评测

执行环境为 Windows x64、Node 24.14.0、pnpm 10.34.1。所有用户、记忆、目标、资料与数据库均是临时夹具。源码基线 d5221ee 加当前工作区改动；组员可用同一锁文件与入库夹具复现。下述基线使用本地夹具；真实模型抽测另列于文末。安装和运行方法见 [开发交接与迁移](08_开发交接与迁移.md)。

## 工作流

`pnpm eval:agent` 回放 10 类意图，每类 12 种表述，总计 120 条。覆盖普通聊天、不确定时刻的澄清、七个原工具及资料查询。确定性模型提供标准工具调用；执行真实注册表、校验、授权、SQLite 和人工确认逻辑。工具选择匹配、预期必要参数匹配、完成用例分别为 120/120、120/120、120/120。这个实验验证本地执行合同，无法度量 DeepSeek 阅读问句后的工具选择准确率。输出含逐例耗时、失败项和用量是否已知。

独立故障用例覆盖跨对话未确认草案、撤权、跨空间检索、同键异参、并发确认、进程重启恢复、资料更新失败、过期引用、迁移和双端副本恢复。重启用例在 SQLite 已有提案时结束进程生命周期，从新 HTTP 服务恢复后并发确认两次，检查一个提醒和零次模型重发。备份试验使用合成浏览器目录；真实浏览器的账号绑定和加密 cookie 仍需在原设备演练。

## 检索

语料为 12 份合成单块中文短文，每份 3 个词面题和 2 个改写题，共 60 个有答案问题；另有 6 个无答案探针。每题标注唯一目标段落。除词面基线外，使用本地 BGE 中文 q8 模型，修订号与路径配置见 08。该语料主要测同义问法，不能代表长 PDF 或真实用户问题的分布。

|路径|60 题前五命中|24 个改写题前五命中|整体 MRR@5|
|---|---:|---:|---:|
|默认 FTS5|43/60|8/24|0.708|
|精确向量排序，无拒答阈值|60/60|24/24|0.975|
|RRF 混合排序，无拒答阈值|60/60|24/24|0.885|
|产品可选本地混合检索，余弦阈值 0.5|52/60|16/24|0.833|

在 6 个无答案探针上，默认与产品可选路径均返回 6 次空结果。词面完全不同的“单车瘪了怎样找出损坏位置”在一次单文档测试中与目标块余弦为 0.446，产品阈值会将其排除。保留此例用于后续扩充近义词和困难负例，避免只优化正例命中。

在同机 1 万行合成 FTS 表上，热缓存的 100 次排序检索 p95 约 2 ms；这项微基准未计入模型推理、HTTP、分块或端到端响应时间。Windows 上 sqlite-vec 0.1.9 加载成功，60 个查询的原生向量最近邻首位与精确扫描均一致；另验证按空间查询与删除。Linux 纳入 CI，当前本机未取得 Linux 执行结果。产品默认保持 FTS5。即使已安装评测扩展，产品仍只在显式配置本地模型时启用精确向量与 RRF 路径。

## 复现与结果边界

所有命令在 web 执行。运行 `pnpm test:agent` 检查真实 SQLite、PDF 解析、Windows/Linux 本平台原生扩展、来源删除、隔离和恢复；运行 `pnpm eval:agent`、`pnpm eval:knowledge` 输出匿名 JSON。语义对照需设置 XINYU_EVAL_MODEL_DIR。用例及标签在 tests/xinyu/fixtures 内。模拟模型与真实供应商的成绩应分别保存；新增样例后必须重新计算分母。

发布时应复测更大规模、多块中文 PDF 的页级引用、语义拒答、工具选择和真实模型用量。现有浏览器用例已经走通引用可打开、来源删除后不可打开的流程，尚无独立人工标注的真实模型“引用正确率”。

## Windows 交付检查

类型检查为 0 错误、0 警告。17 个前端测试文件共 81 项通过，24 项 Agent 服务测试和 8 项网关测试通过。干净临时目录以冻结锁文件完成安装、构建并通过无密钥生产启动检查。最终桌面 Chromium 回归 21/21 通过，耗时约 6 分钟，终端未报告重试失败或 flaky 用例。先前在同时构建及运行多个浏览器时出现启动超时；代理测试现直接进入成长页，秒数为零的时间输入使用 Chromium 规范格式。部分首次启动仍有上游解码器针对空配置块的控制台诊断，本次回归中页面成功启动。

## GitHub 交接与供应商抽测（2026-11-24）

功能提交 8e94ffe 在 GitHub 全新克隆后通过冻结依赖安装、生产构建和无密钥启动检查。相同提交的 [GitHub Actions 运行](https://github.com/lkq-guji/emotion-agent/actions/runs/45360104719) 在 Ubuntu 与 Windows 均通过。另一次并行运行的 Ubuntu 浏览器 smoke 首次失败，应保留此波动记录。

真实 deepseek-flash 工作流抽测共 5 例、10 次模型请求。工具匹配 4/5、必要参数匹配 3/5、按严格判定完成 3/5。普通倾诉、专注和提醒通过；读书目标的工具匹配失败，偏好记忆的工具匹配但参数未完全匹配。此结果不足以推断完整 120 例准确率。

另用单页合成 Markdown 做三次独立对话，共调用模型 6 次。已分享时，回答正确给出暗号并引用可打开的第 1 页；询问未收录的电话号码时模型明确表示资料不足，但附带了截短且无法打开的片段编号；撤销分享后，出站请求未包含测试暗号，模型表示无可用依据。此项验证的是抽取片段引用，未测真实模型的多页 PDF 页码准确率。
