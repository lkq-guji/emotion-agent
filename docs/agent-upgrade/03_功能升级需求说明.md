# 03　功能升级需求说明（待开发）

使用者从桌面端与小屿对话、审阅确认卡、管理资料；维护者在本机查看脱敏执行记录、运行回归。初版仅面向本机。以下编号对应 05 的开发任务与 06 的验收。

|需求|正常行为|失败、边界与用户可见结果|
|---|---|---|
|R1 上下文与授权|仅提供当前对话、已授权相关记忆、必要任务字段；候选只用于其原卡片。|另一会话草稿不可出站；撤权立即停止后续调用；无法核验的旧记忆要求核验或暂不使用。|
|R2 工具与确认|现有七工具沿用名称；读直接执行；模型请求写操作显示字段、来源及后果，确认后显示真实回执。|未知工具、额外字段、过期时间、跨空间 ID、越权或二次异参提交均拒绝。普通倾诉无需强制调用工具。|
|R3 恢复|断连后查看原 run，刷新看到原确认卡；可安全重试的步骤显示继续入口。|重试只提交一次任务，拒绝/撤权后不能恢复原写入；结果未知的模型调用由使用者决定重发。|
|R4 可观测|在本空间展开步骤、用量、耗时、失败和恢复原因。|没有 usage 时显示未知；删除来源会移除可关联调试记录；默认不记录原文、文件内容或凭据。|
|R5 资料管理|选择本地 PDF、TXT、MD；明确提示解析位置、是否向供应商发送片段；展示排队、处理、可用和失败。|首版建议每文件 10 MiB、PDF 200 页；二进制伪装、加密或没有文本层的 PDF 给出原因；导入失败不产生可检索残片。|
|R6 检索与引用|对“根据我的资料……”使用知识查询工具，返回片段、文件名、页/标题、版本，支持点回原文；没有依据时说明未找到。|资料关闭时不能检索；文档内指令不能触发执行；更换文件失败仍可搜索上一版，删除成功后旧引用显示来源已删除。|
|R7 双端数据治理|区分关闭使用、撤回某条授权、删除资料和删除整段来源；按类型说明会影响哪些对象。|浏览器提交后断网可核对未完成回执；删除和重试相撞时删除优先；跨空间访问统一按资源不可用处理。|
|R8 工程交接|新成员可从锁文件安装、使用自有密钥配置模型，假模型可跑确定性测试。|缺少密钥时明确显示未配置；支持配置与库版本检查、备份及恢复演练。新增模型评测按需运行并披露费用。|

### 两条端到端验收故事

用户说“为明天下午三点的复习建一个提醒”。测试固定时钟与时区。卡片显示本地时间；直到点击确认，任务列表都没有新增。连续确认、刷新、重启后仍只有一条；到期后在应用内可见。若用户只说“晚点”，先澄清时间。

用户导入带页码的复习资料，问“第几章提到这一点”。回答可以定位原页；切换到另一个空间没有结果。替换文件后旧内容不能参与新检索，删除后点击旧引用提示来源已删除。该流程不会产生长期记忆。

### 范围与放行

P0 覆盖出站授权、备份、幂等；P1 覆盖恢复、诊断、导入、关键词检索和引用；向量增强需以兼容性和评测结果放行。保留既有桌面页面、存档格式及用户主动填写的任务流程。OCR、联网爬取、公共账号、跨设备同步、离线系统通知不属于首版。
