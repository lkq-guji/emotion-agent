# 心屿智伴 · 个人陪伴 Agent 改造计划

更新日期：2026-11-05。产品主线为本地桌面应用，不再参加比赛。

## 第一版的完整体验

用户在对话中表达目标 → 小屿检索已授权的相关记忆 → 调用工具提出可检查的安排 → 用户确认 → 后台实际保存目标/提醒/专注计时 → 到期提示 → 完成、调整或取消 → 下次对话回顾真实结果。

保留 Svelte 5、像素小岛与房间、原聊天存档、日记、画像、衣橱与窗景。模型继续使用用户自行配置的 DeepSeek / OpenAI 兼容服务。模型失败显示实际错误，不返回假回复。

## 实施顺序与验收

1. **产品定位和归档**：比赛 Python 骨架、训练/提交说明归档；更新主 README、接手入口和 CI。许可、素材来源与旧提交保留。
2. **可执行的 Agent 服务**：扩展现有 Node 网关，加入有次数/时间上限的工具循环；只注册陪伴工具。读取相关记忆和真实进展；写入操作先生成待确认卡。验证非法参数、重复请求、撤销、模型错误和停止。
3. **持久任务**：使用 Node 24 内置 SQLite，保存待确认操作、目标、提醒和专注计时。后台调度到期状态；重启补查到期任务。验证持久化、重复确认、跨浏览器空间隔离与完整删除。
4. **界面集成**：对话展示动作和执行结果；成长页管理目标、提醒和计时；全站提供温和的到期提示。保持两种聊天布局、键盘操作、日夜配色和减少动态行为。
5. **回归与交接**：运行类型检查、单元/服务测试、真实 HTTP 工具循环、构建和无密钥启动；在桌面浏览器检查确认、刷新恢复、取消、锁定与清空。真实模型联调只使用自造内容，不发送个人记录。

## 数据与运行边界

- 浏览器继续保存原聊天、已确认记忆和画像；相关记忆按问题筛选，不再无上限注入全部记录。
- SQLite 保存任务与执行状态，默认位于 `web/.runtime/xinyu-agent.sqlite3`，禁止提交。
- 持久浏览器 Cookie 对应独立任务空间；本机服务仍检查 Host、Origin 与会话。应用锁是界面锁，不是磁盘加密或公网账号体系。
- 记忆候选需逐条确认后写回浏览器。关闭记忆、删除对话和清空数据应停止未来引用，并处理后台关联状态。
- 提醒由后台服务调度；应用内展示到期提示。服务关闭时不发送通知，重新启动后显示错过的到期事项。
- 第一版以相关词匹配检索作为可检查的基线；向量检索、任意回复配音、语音输入和公网多人部署留待后续独立验收。

## 首轮验收例子

- 确认“英语学习喜欢 25 分钟一段”，在新对话请求学习安排时能找到这条偏好。
- 目标与提醒在确认前不生效；重复点击/重试不重复创建。
- 确认后刷新页面和重启服务仍能查看，提醒可以改期、取消或完成。
- 删除记忆后下一次请求不再引用；清空本机数据同时移除这个任务空间。
- 无密钥可以管理本机任务，AI 对话明确提示模型未配置。
