应用与开源组件

心屿智伴的中文像素界面、小岛交互与陪伴模块由本项目开发。聊天与存储基础来自 RisuAI，继续保留其 GPL v3 许可证、上游署名与源码声明。Gato Café 提供交互参考与猫叫素材，保留 MIT 许可证。

部分文字、滑杆、玻璃、导航与卡片交互参考 David Haz 的 React Bits，许可为 MIT + Commons Clause。日记开合参考 StPageFlip（Nodlik，MIT）与 Bits UI（MIT）。均以 Svelte、Canvas、SVG 或 CSS 独立适配，未引入另一套前端。

像素绘画与角色

原设计与小岛初始素材由项目用户提供。新增房间、窗景、同角色衣橱和行走图集由本项目借助 image_gen 制作；原文件、提示词与处理记录保存在源码 docs/xinyu 素材清单中。提供素材不代表已取得所有第三方商业再分发权利。

互动语音

小屿的原创固定问候使用 zh-CN-XiaoyiNeural 与 zh-CN-XiaoxiaoNeural 语音制作，并调整语速与音高。没有克隆真人，也不将私人聊天用于这些问候的合成。语音参数与短句 · edge-tts · 语音名称来源。

窗边环境音

雨声来自 alxl 的 Rain on Window Loop 和 Kresiek The Furry 的 AMB Rain Loop 1，均以 CC0 1.0 提供。本项目处理滤波、响度与循环接缝；雪天轻风由本项目合成。处理参数与来源 · 雨声署名。
