# 个人陪伴 Agent 界面验收

日期：2026-11-05。模式：full。范围为本轮新增的对话动作卡、成长页任务管理、到期提示和设置项；Svelte 5 / TypeScript，沿用普通 CSS 与 `--xy-*` 语义色。原小岛、衣橱和场景不重新设计；已有桌面回归仍执行。

## 覆盖

| 分类 | 实际检查 | 结果 |
| --- | --- | --- |
| Typography | 日/夜截图；动作标题、步骤、任务状态、动态计时与日期 | 标题与正文有层级；计时和日期使用等宽数字；长标题允许折行 |
| Surfaces | AgentActions、AgentWorkspace、AgentNotice；1440×900 与 1280×720 | 沿用原玻璃表面与主题色；操作区域至少 40px；无外层多余滚动 |
| Animations | 按压、hover、focus、减少动态；浏览器 CDP 动画播放速率 0.1 | 按压终值 scale(0.96)，可中断；减少动态时 transition=0s；未添加卡片循环或逐字入场 |
| Icons | 状态方块、任务标签与操作入口 | 使用现有像素符号与文字，不新增另一套图标库；状态不依赖颜色或动作单独表达 |
| Performance | 开关、停止、轮询、锁定与离开页面；构建结果 | 后台每秒调度，界面五秒轮询；隐藏/锁定时停止轮询；未新增动画依赖或全页动画 |

## 本轮界面变化

| 级别 | 位置 | 之前 | 之后 | 原因 |
| --- | --- | --- | --- | --- |
| HIGH | `src/xinyu/components/AgentActions.svelte:1` | 聊天只能展示文字，缺少执行前审阅入口 | 展示标题、步骤、计时、可调整提醒时间与明确的确认/拒绝；处理中禁止重复操作 | 执行状态必须清楚，用户能确认具体内容 |
| MEDIUM | `src/xinyu/pages/Chat.svelte:28` | 新动作出现时可能被输入区遮住，切换对话仍残留上一轮工具摘要 | 跟随阅读位置滚动；输入区保留待确认入口；摘要只显示在来源对话 | 保持可发现性及上下文一致 |
| MEDIUM | `src/xinyu/components/AgentWorkspace.svelte:1` | 成长页只有简单目标复选框 | 按目标、提醒、专注、已结束分类；真实状态、改期、取消、回顾、删除 | 把后续行动放在统一位置，避免用计时推断专注质量 |
| MEDIUM | `src/xinyu/components/AgentNotice.svelte:1` | 没有全站到期回执 | 温和提示、收起入口与完成操作；锁定后隐藏内容 | 到期状态可见，同时控制干扰和锁屏信息泄露 |
| LOW | `src/xinyu/pages/Settings.svelte:29` | 没有 Agent 模式与任务存储说明 | 明确陪伴助手开关、确认原则、后台状态和任务管理入口 | 模式切换和保存位置可理解 |
| LOW | 上述新增组件样式 | 新功能尚无一致样式约束 | 复用主题色、40px 点击区、等宽数字、指定属性过渡和减少动态 | 与既有像素界面统一，避免重复动效干扰 |

## 考虑后未采用

| 位置 | 候选 | 未采用原因 |
| --- | --- | --- |
| 动作卡 | 每出现一张卡片都做分段弹跳入场 | 聊天属于高频操作；静态状态和轻按反馈已足够 |
| 到期提示 | 自动播放音效、遮挡页面的强制弹窗 | 会打断陪伴体验，当前采用可收起的应用内提示 |
| 新任务表面 | 引入额外 React 卡片/动画系统 | 项目已有 Svelte 和主题变量；增加第二套运行系统不能改善本轮流程 |

## 验证记录

- `pnpm check`：0 错误、0 警告。
- `pnpm test`：81 项通过；`pnpm test:gateway`：8 项通过；`pnpm test:agent`：14 项通过。
- 桌面整套回归 61/62。唯一失败是旧设置页仍断言 8 张卡片，新版为 9 张；更新断言并检查新增模式开关后，与新增迁移/键盘用例一起定向 3/3 通过。两个集合合计覆盖 64 个不同用例。
- 新 Agent 浏览器用例验证真实 HTTP 与 SQLite 链路，模型端为隔离工程替身：确认前无任务、确认后保存、刷新恢复、记忆授权和删除、改期/取消、模型错误/停止、跨浏览器隔离、完整清除、旧目标迁移及删除、键盘、减少动态和锁定隐藏提醒。
- 新增 7 项 Agent 桌面流程最后再次全部通过；切换对话后不展示另一段对话的工具摘要。
- 动作卡、成长页的日/夜截图已人工查看；截图、慢速按压检查、日志和 trace 保存在忽略目录，不随源码提交。慢速检查通过 CDP 设置播放速率 0.1，检查 hover/按压/释放；按钮高约 42.8px，键盘 Tab 焦点使用原全局 3px 实线焦点样式。
- 干净副本的锁定依赖安装、类型检查、14 项 Agent 测试、构建和无密钥生产启动通过；仓库没有私人的环境文件和任务库。
- 真实 DeepSeek 联调仅使用自造英语偏好：调用 `get_progress` 与 `create_goal`，提出 25 分钟计时，确认前 0 条任务，确认后目标与专注均落库。它验证单条链路，不能当作总体模型成功率。

结论：Approve，本轮范围没有剩余的可操作界面问题。未验证范围：macOS、低配置硬件帧耗时、长时间多日运行、任意回复语音及公网多人使用；这些能力没有在本轮交付中宣称完成。旧存档解码器在空可选插件块上仍可能输出可恢复诊断日志，桌面测试未出现未捕获页面异常。
