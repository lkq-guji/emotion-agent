# 组员接手清单 · 2026-10-29

## 当前能做什么

桌面九页、小岛进屋、真实 API 对话、停止/重试、历史、授权记忆、情绪多维记录与回看、可更正画像、目标、衣橱、动态窗景/自定义媒体、日夜/亮度/天气、独立音效和应用锁已实现。API 密钥由各成员自行配置，仓库不提供共享账号或凭据。

聊天与个人记录目前是浏览器本地单用户数据。新浏览器没有旧记录，这是预期行为。不要把队长的数据库、导出记录、应用密码或自定义上传媒体加入仓库。

正式预测的 `memory_refs` 是否允许非空，以根目录需求和官方最终入口为准。网页的自由文本画像和个人记忆不可直接拼进正式预测 JSON。

## 分工与改动规则

- A 优先动根目录模型代码和训练配置；B 优先动数据/评测。不要为接网页而擅自修改官方原文件或混入假标签。
- C 维护 `web/`，先按 README 无密钥启动，再填写自己的配置。接服务前和 A/B 约定协议与失败码。
- 日常分支从最新 `develop` 创建，PR 合入 `develop`；验收后发布到 `main`。修改 `contracts.py`、`domain.ts` 或网关字段时写出迁移和受影响模块。
- 每轮检查至少保留类型/单元、网关、静态资源、构建和受影响桌面测试。测试报告留在被忽略的运行目录，小型汇总写进 `docs/experiments/`。

## 本次整理排除项

没有复制 `.env.local`、聊天数据、浏览器 profile、node_modules、dist、运行缓存、截图/trace、旧调试脚本和大批历史审查报告。旧 LPC 人物、旧版窗景/房间素材与未采用的原生打包/部署脚本不随 Web 交接版提交。运行中的图像、18 份服装进屋视频、语音、雨声、tokenizer 和必要 WASM 保留，并有资源校验清单。

本轮未开展新训练或官方评分，也未替组员验证各自的 API 账号。最终本地与 CI 验证结果见仓库总状态及 Actions 对应提交。
