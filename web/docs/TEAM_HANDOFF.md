# 个人陪伴 Agent 开发交接

更新日期：2026-11-05。比赛材料已归档，不继续训练、官方结构化输出或正式比赛提交。

## 本轮用户流程

在对话中说明学习或生活目标 → 检索授权记忆 → 小屿提出待确认安排 → 用户确认 → 实际保存 → 成长页管理 → 后台到期 → 完成、改期或取消 → 用户主动发起回顾。

保留像素小岛、房间、原聊天、情绪日记、画像、衣橱与动态窗景。只验收桌面端。

## 运行

在 web/ 使用 Node 24.14.0、pnpm 10.34.1，依 README 启动。自己的密钥放 .env.local，数据库默认 .runtime/xinyu-agent.sqlite3；两者禁止提交。需要恢复任务时保留数据库与同一浏览器任务 Cookie。

## 后续优先级

| 优先级 | 工作 | 验收 |
| --- | --- | --- |
| P1 | 固定任务集与真实模型评测 | 任务完成率、误操作率、取消、重复请求、时区、延迟和模型用量 |
| P1 | 记忆召回质量与冲突处理 | 区分相关/不相关、纠正旧偏好；用户删改后未来请求生效 |
| P1 | 长期行动回顾 | 依据真实完成与反馈，不从计时推断实际专注质量 |
| P1 | 低配置性能与任务历史分页 | 测量帧耗时/内存，列表增长时不隐藏到期提醒 |
| P2 | 任意回复配音与语音输入 | 授权、播放中断、环境音独立和隐私说明完整 |
| 按需 | 公网多人部署 | 登录、服务端授权、每用户隔离、备份和配额均需独立实现与测试 |

不要因为有 Agent 工具就接入任意文件系统或外部通信。先把有限的陪伴工具做可靠；新增写入工具必须有参数校验、确认、幂等、停止和删除路径。

## 开发检查

~~~sh
pnpm check
pnpm test
pnpm test:gateway
pnpm test:agent
pnpm verify:assets
pnpm verify:repo
pnpm build
pnpm test:startup
pnpm exec playwright install chromium
pnpm test:e2e
~~~

工程接口替身只用于测试。实际产品始终调用所配置的模型，失败明确显示错误。测试报告与截图保存在忽略目录；小型结论写入当前状态或 QA 文档。
